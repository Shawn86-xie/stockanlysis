# 医疗量化研报系统 (MedPortfolio 2026)

一个专为科研工作者设计的医疗行业量化投资分析系统，集成了AI资讯分析、风险预警、组合优化和模拟交易等功能。

## 📋 项目简介

**医疗量化研报系统 (模块化版)** 是一个基于Streamlit的交互式量化分析平台，专门针对医疗行业股票进行深度分析和投资决策支持。系统通过集成多种量化分析工具和AI技术，为科研工作者提供专业的调仓决策支持。

### 核心特点
- 🎯 **医疗行业专注**：预设医疗行业核心标的库，支持自定义扩展
- 🤖 **AI深度分析**：集成DeepSeek API进行医疗资讯智能分析
- 📊 **多维度分析**：涵盖基本面、技术面、风险管理和组合优化
- 🖱️ **交互式可视化**：支持交互式图表操作，提升用户体验
- 🔄 **手动控制**：新增"开始统计"按钮，支持随时调整标的后再启动分析

## ✨ 主要功能

### 1. 💡 AI资讯深度研判
- 自动抓取最新医疗行业新闻
- 使用DeepSeek API进行情感分析和投资建议
- 智能评分系统（⭐️⭐️⭐️⭐️⭐️五星制）

### 2. 🚦 买卖与风险预警
- **实时交易信号生成**：基于RSI、均线等技术指标
- **风险提醒系统**：自定义止损阈值预警
- **交互式曲线图表**：
  - 单击突出显示特定标的
  - 其他线条自动变暗虚化（透明度0.5）
  - 下拉选择器快速切换关注标的
  - 图例点击隐藏/显示功能

### 3. 🕸️ 板块相关性分析
- 资产相关性矩阵可视化
- 防范共振风险，优化资产配置

### 4. 📊 权重优化实验
- 蒙特卡洛模拟（3000+次随机组合）
- 夏普比率最大化权重分配
- 有效前沿图展示
- 前10个优选组合详细对比

### 5. 📈 模拟交易
- 持仓分析与市值计算
- 基于最优权重的调仓建议
- 可视化当前权重与建议权重对比

## 🚀 安装与运行

### 环境要求
- Python 3.9+
- pip 包管理器

### 安装步骤

1. **克隆项目**
```bash
git clone https://github.com/Shawn86-xie/stockanlysis.git
cd stockanlysis
git checkout 1.0.1
```

2. **创建虚拟环境（推荐）**
```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate
```

3. **安装依赖包**
```bash
pip install -r requirements.txt
```

如果尚未创建requirements.txt，请安装以下核心依赖：
```bash
pip install streamlit pandas matplotlib seaborn plotly akshare numpy
```

4. **配置API密钥**
   1. 在Streamlit侧边栏输入DeepSeek API密钥
   2. 或编辑`config.json`文件添加：
   ```json
   {
     "deepseek_api_key": "your_api_key_here"
   }
   ```

5. **运行应用**
```bash
streamlit run app.py
```
访问 http://localhost:8501

## 📖 使用说明

### 首次使用指南

1. **标的库管理**（侧边栏）
   - 使用搜索功能添加新标的（支持代码/名称模糊匹配）
   - 管理现有标的分类（核心组合、科研/肾科等）
   - 保存标的库到配置文件

2. **参数设置**
   - 风险提醒阈值：设置止损触发条件（默认-5%）
   - 模拟次数：蒙特卡洛模拟数量（默认3000次）

3. **开始分析**
   1. 在侧边栏勾选要分析的标的
   2. 点击"🚀 开始统计"按钮启动分析
   3. 系统将自动获取数据并进行分析

### 交互功能详解

#### 曲线突出显示功能
在"买卖与风险预警"标签页中：
- **下拉选择器**：从列表中选择要突出显示的股票
- **图例交互**：点击图例可隐藏/显示对应曲线
- **视觉效果**：
  - 选中标的：线条宽度3px，不透明度1.0
  - 其他标的：线条宽度1px，不透明度0.5（变暗虚化）

#### 手动控制分析
- 新增"开始统计"按钮，避免自动分析干扰
- 支持随时调整标的选择后再启动分析
- 分析状态保存在session中，页面刷新不影响


### 模块说明

- **med_pro_system.py**：主界面和交互逻辑
- **data_fetcher.py**：
  - `fetch_stock_data()`：获取股票历史数据
  - `get_signals()`：生成交易信号和风险提醒
  - `monte_carlo_simulation()`：蒙特卡洛模拟
  - `analyze_portfolio()`：持仓分析
  - `search_stock_info()`：股票信息搜索
- **ai_analyzer.py**：`deepseek_analyze()` - DeepSeek API集成
- **config.py**：配置文件的加载和保存

## ⚠️ 注意事项

### 数据源
- 使用akshare获取A股市场数据
- 需要稳定的网络连接
- 数据更新频率：交易日收盘后

### API限制
- DeepSeek API有调用频率限制
- 建议使用自己的API密钥
- AI分析功能需要手动触发

### 性能优化
- 首次获取数据可能需要较长时间
- 蒙特卡洛模拟次数影响计算时间
- 建议标的数量：5-10个为佳

### 风险提示
1. **历史数据不代表未来表现**
2. **量化模型存在固有局限性**
3. **投资决策需结合专业判断**
4. **系统仅供研究和参考使用**
