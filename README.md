## 📋 项目简介

**医疗量化研报系统** 是一个基于Streamlit的全功能量化分析平台，集成了AI资讯分析、技术面分析、形态挖掘、风险管理和投资组合优化等功能。系统不仅支持医疗行业深度分析，还提供全市场5000+只A股的形态挖掘和技术分析能力，为投资决策提供全方位的数据支持。

### 核心特点
- 🎯 **医疗行业专注**：预设医疗行业核心标的库，支持自定义扩展
- 🔍 **全市场覆盖**：支持5000+只A股的形态挖掘和技术分析
- 🤖 **AI深度分析**：集成DeepSeek API进行资讯智能分析和宏观环境研判
- 📊 **多维度分析**：涵盖基本面、技术面、形态学、风险管理和组合优化
- 🖱️ **交互式可视化**：支持交互式图表操作，框选分析，提升用户体验
- ⚡ **高性能计算**：本地K线数据库缓存，多线程并行处理
- 🔄 **手动控制**：新增"开始统计"按钮，支持随时调整标的后再启动分析
- 📈 **形态挖掘**：触底反弹、MA60突破等经典形态自动识别

## ✨ 主要功能

### 10. ✅ 数据完整性检查

- **置信度评估**：数据可靠性评分系统

### 11. 🔍 形态挖掘工具

#### 触底反弹形态挖掘
- **三阶段模型**：前期下跌 → 触底震荡 → 反弹启动

## 🚀 安装与运行

### 环境要求
- Python 3.9+
- pip 包管理器

### 安装步骤

1. **克隆项目**
```bash
git clone https://github.com/Shawn86-xie/stockanlysis.git
cd stockanlysis
git checkout 1.3.1
```

2. **创建虚拟环境（推荐）**
```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate
```

3. **安装依赖包**
```bash
pip install -r requirements.txt
```

如果尚未创建requirements.txt，请安装以下核心依赖：
```bash
pip install streamlit pandas matplotlib seaborn plotly akshare numpy
```

4. **配置API密钥**
   1. 在Streamlit侧边栏输入DeepSeek API密钥
   2. 或编辑`config.json`文件添加：
   ```json
   {
     "deepseek_api_key": "your_api_key_here"
   }
   ```

5. **运行应用**
```bash
streamlit run app.py
```
访问 http://localhost:8501

## 📖 使用说明

### 首次使用指南

系统采用**主界面标签页布局**，核心操作均在主界面完成，侧边栏仅保留系统设置。

#### 主界面三大标签页

1. **标的选择与分析**
   - 横向紧凑布局展示所有标的（每行5个）
   - 按分类分组显示，支持快速勾选
   - 操作按钮：开始统计分析 / 刷新历史数据 / 全选取消

2. **标的库管理**
   - 左侧：搜索添加（支持代码/名称模糊匹配）或手动输入
   - 右侧：查看和删除现有标的
   - 支持初始化/刷新本地市场库（5000+只A股）

3. **交易录入**
   - 左侧：录入新交易（选择标的、买入均价、数量、日期）
   - 右侧：当前持仓记录，支持**修改**和删除操作

#### 侧边栏设置

- **API密钥**：配置DeepSeek API密钥
- **分析参数**：风险提醒阈值、蒙特卡洛模拟次数、新闻获取数量
- **设置保存/加载**：保存当前配置或加载已保存配置

### 分析流程

1. 在「标的选择与分析」标签页勾选要分析的标的
2. 点击「开始统计分析」按钮
3. 系统自动获取数据并计算分析结果
4. 通过下方导航按钮跳转到各功能模块

### 交互功能详解

#### 曲线突出显示功能
在"买卖与风险预警"页面中：
- **下拉选择器**：从列表中选择要突出显示的股票
- **图例交互**：点击图例可隐藏/显示对应曲线
- **视觉效果**：
  - 选中标的：线条宽度3px，不透明度1.0
  - 其他标的：线条宽度1px，不透明度0.5（变暗虚化）

#### 持仓记录管理
- 支持修改已录入的持仓记录（买入均价、买入数量）
- 点击「修改」按钮进入编辑模式，修改后点击「保存」确认

### 形态挖掘工具使用

#### 触底反弹形态挖掘
1. 访问「触底反弹挖掘」页面
2. 查看K线数据库状态，确保有足够的缓存数据
3. 可选择批量下载或增量更新K线数据
4. 点击「开始扫描」按钮，系统将自动分析全市场标的
5. 查看Top10匹配度最高的标的，点击可查看详细图表

#### MA60均线突破挖掘
1. 访问「MA60趋势突破挖掘」页面
2. 系统自动扫描全市场K线数据
3. 识别满足以下条件的标的：
   - K线由下向上穿越60日均线
   - 连续5日站稳MA60
   - 均线斜率走平或上行
   - 成交量动能良好
4. 查看推荐列表和可视化图表

## ⚠️ 注意事项

### 数据源
- 使用akshare获取A股市场数据
- 需要稳定的网络连接
- 数据更新频率：交易日收盘后

### API限制
- DeepSeek API有调用频率限制
- 建议使用自己的API密钥
- AI分析功能需要手动触发

### 性能优化
- 首次获取数据可能需要较长时间
- 蒙特卡洛模拟次数影响计算时间
- 建议标的数量：5-10个为佳
- **K线数据库**：首次使用形态挖掘工具需批量下载数据，建议选择合适的时间窗口
- **并行计算**：标的优先度雷达支持5线程并行，提升分析速度

### 风险提示
1. **历史数据不代表未来表现**
2. **量化模型存在固有局限性**
3. **投资决策需结合专业判断**
4. **系统仅供研究和参考使用**

## 🔧 故障排除

### 常见问题与解决方案

#### 1. 配置文件加载不稳定

**问题描述**：每次启动应用时，有时加载一组参数，有时加载另一组参数，配置不稳定。

**根本原因**：[config.py](config.py#L318-L337) 中的测试代码会在直接运行时覆盖 `config.json` 文件。

**解决方案**：
- ✅ 已将测试代码改为只读模式，不再修改配置文件
- ✅ 删除或重命名 `config.json.bak` 文件以避免混淆

**相关文件**：`config.py`（测试代码已安全化）

---

#### 2. AI 资讯页面无法运行

**问题描述**：访问 "AI资讯深度研判" 页面时出现代理相关错误：`__init__() got an unexpected keyword argument 'proxies'`

**根本原因**：
1. akshare 字段名不匹配（`发布时间` vs `新闻发布时间`）
2. OpenAI SDK 使用 httpx 而非 requests，代理配置冲突
3. 批处理错误处理过于严格，一个失败导致全部失败

**解决方案**：
- ✅ 修正 akshare 字段名映射 ([news_service.py](services/news_service.py#L75-L89))
- ✅ 彻底禁用代理：
  - 清除所有代理环境变量
  - Patch `httpx.Client` 和 `httpx.AsyncClient` ([ai_analyzer.py](ai_analyzer.py#L13-L40))
  - Patch `requests` 相关类 ([news_service.py](services/news_service.py#L15-L106))
- ✅ 改进批处理逻辑，部分失败也能返回成功结果 ([news_service.py](services/news_service.py#L131-L137))
- ✅ 添加 API Key 检查和详细错误提示 ([01_ai_news.py](pages/01_ai_news.py#L113-L139))

**相关文件**：
- `services/news_service.py`（代理禁用 + 字段名修正）
- `ai_analyzer.py`（httpx 代理禁用）
- `pages/01_ai_news.py`（错误处理优化）

---

#### 3. 修改配置文件后不生效

**问题描述**：修改 `config.json` 后，应用仍然使用旧的配置数据。

**根本原因**：应用使用 `session_state._config_cache` 缓存配置，修改文件后不会自动重新加载。

**解决方案**：
- ✅ 在侧边栏添加 **"🔄 刷新配置"** 按钮 ([app.py](app.py#L241-L257))
- 使用方法：修改 `config.json` 后，点击此按钮即可重新加载配置，无需重启应用

**相关文件**：`app.py`（新增刷新配置功能）

---

#### 4. 网络请求代理冲突

**问题描述**：在有代理环境的系统中，akshare 和 OpenAI SDK 可能出现代理配置冲突。

**完整解决方案**：

1. **清除环境变量**（在导入库之前）：
   ```python
   os.environ.pop('HTTP_PROXY', None)
   os.environ.pop('HTTPS_PROXY', None)
   # ... 清除所有代理相关变量
   ```

2. **Patch httpx**（OpenAI SDK 使用）：
   ```python
   def _patched_httpx_client_init(self, *args, **kwargs):
       kwargs.pop('proxies', None)
       kwargs.pop('proxy', None)
       kwargs['trust_env'] = False
       return _original_httpx_client_init(self, *args, **kwargs)
   ```

3. **Patch requests**（akshare 使用）：
   ```python
   # Patch requests.get, requests.post, Session, HTTPAdapter, PoolManager
   # 详见 services/news_service.py
   ```

**技术细节**：
- OpenAI SDK (v1.3.0) 使用 `httpx` 而非 `requests`
- httpx 使用 `proxy`（单数）参数，不是 `proxies`（复数）
- 需要同时 patch 两个库的底层网络层

**相关文件**：
- `ai_analyzer.py`（httpx patch）
- `services/news_service.py`（requests patch）

  - 从标的优先度雷达快速跳转到K线实验室

#### 版本更新 (1.2.2) - 2026年1月18日
- ✅ **交易日智能识别**：数据完整性检查和置信度审计现已支持A股交易日历（含2025-2026年节假日），避免周末/节假日误报
- ✅ **基准对齐度修复**：修复非交易日导致的"基准对齐度FAIL"异常判定问题
- ✅ **AI分析历史记录增强**：
  - 支持多条历史记录保存（不再覆盖）
  - 按标的名称汇总展示
  - 支持单条记录删除
  - 自动数据格式迁移（v1→v2）
- ✅ **数据接力模式**：所有分析页面支持从主控台接力已加载的数据，避免重复API请求
- ✅ **并行数据获取优化**：批量数据初始化和更新支持多线程并行（5线程），显著提升加载速度
- ✅ **页面间标的同步**：从"标的优先度雷达"快速跳转到"独立K线分析"时，自动同步选中的标的并启动分析，无需重新选择

#### 版本更新 (1.2.1) - 2026年1月9日
- ✅ **实盘持仓监测增强**：新增"盈亏总额"指标，支持红涨绿跌A股风格显示

- ✅ **科研判定逻辑**：提供斜率判定、平行通道判定、突破判定等量化形态学分析
- ✅ **信号处理思维**：将医学波形分析思维应用于金融技术面分析
- ✅ **数学引擎增强**：新增math_engine.py，包含fit_trend_line等核心算法
